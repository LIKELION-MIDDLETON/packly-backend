# AI 맞춤 스킨케어 팩 서비스 기능정의서

> 이 문서는 장기 제품 비전입니다. 현재 구현된 백엔드 MVP 계약은
> [`api-contract.md`](./api-contract.md)를 기준으로 하며, 날씨·보유제품·Firewall·배송·사진 규격은 아직 지원하지 않습니다.

## 1. 서비스 정의

사용자의 피부 상태, 안전 정보, 가지고 있는 화장품과 향후 7일 날씨를 함께 분석해 **오늘 사용할 루틴과 필요한 주간 팩을 제공하는 적응형 스킨케어 매니저**다. 매일의 사용 결과를 다음 루틴과 다음 주 패키지에 반영한다.

> 핵심 질문: **“이번 주 내 피부와 날씨에 맞춰, 오늘은 무엇을 어떻게 발라야 할까?”**

## 2. 사용자 흐름

1. 최초 1회, 피부 고민과 알레르기·이상반응 등 안전 정보를 등록한다.
2. 앱 안내에 따라 정면·좌·우 45도 피부 사진을 촬영한다.
3. AI가 피부 상태를 분석하고 7일 날씨와 결합해 이번 주 루틴을 제안한다.
4. 집에 있는 화장품을 등록하면 새 패키지와의 중복·병용 위험을 확인해 루틴을 자동 조정한다.
5. 사용자는 `오늘`에서 아침·저녁 제품, 순서, 부위와 양만 확인한다.
6. 따가움·가려움·홍조가 생기면 `SOS`를 눌러 의심 제품을 중단하고 회복 루틴으로 전환한다.
7. 매일 피드백과 주 1회 재촬영 결과가 다음 주 추천에 반영된다.

## 3. 통합 기능

중복되거나 따로 사용할 이유가 없는 기능은 합쳐, 사용자가 인지해야 할 핵심 기능을 아래 7개로 정리한다.

### 3.1 안전 프로필

**사용자 가치:** 나에게 맞지 않는 제품을 추천받지 않는다.

- 필수: 연령대, 주요 피부 고민
- 선택: 알레르기, 과거 화장품 이상반응, 복용약, 피부질환·치료 이력, 임신·수유
- 위치·사진·민감정보는 각각 필요한 목적에 대해 동의받는다.
- 원본 사진 보관과 AI 학습 활용 동의는 서비스 이용 동의와 분리한다.

### 3.2 안내 촬영·피부 분석

**사용자 가치:** 복잡한 장비 없이 일관된 조건의 피부 상태를 확인한다.

- 정면·좌 45도·우 45도, 총 3장을 촬영한다.
- 흔들림·조명·노출·가림·얼굴 각도를 자동 검사하고 필요하면 재촬영을 요청한다.
- 홍조, 색소, 모공, 피부결, 잔주름, 여드름성 시각 특징을 항목별로 추정한다.
- 수분·피지·민감도는 측정치가 아닌 `추정 위험도`로 표시한다.
- 항목별 신뢰도와 전주 대비 변화를 함께 보여준다.
- 질환성 병변이 의심되거나 분석 신뢰도가 낮으면 진단하지 않고 재촬영 또는 전문기관 안내로 전환한다.

### 3.3 Skin Forecast

**사용자 가치:** 피부 점수보다 `이번 주에 무엇을 바꿔야 하는지`를 안다.

- 정확한 GPS를 저장하지 않고 행정동·기상 격자 수준으로 변환한다.
- 기온·습도·UV·강수·날씨 변화를 7일 피부 위험 요인으로 변환한다.
- 결과는 `피부 상태 + 날씨 예보 + 이상반응 이력`이 이번 주 루틴에 어떻게 반영됐는지 한 문장으로 설명한다.
- 여행지·실내 습도·미세먼지·야외 활동은 후속 환경 정보로 통합한다.

### 3.4 루틴 디자이너 + Skin Firewall

**사용자 가치:** 새 제품뿐 아니라 집에 있는 화장품까지 함께 고려한 주간 루틴을 받는다.

- 보유 화장품은 이름 검색 또는 바코드 스캔으로 등록한다.
- 제품을 추가·제거하면 주간 루틴을 자동 재계산한다.
- 아래 순서로 제품 후보를 걸러낸 뒤 피부·날씨 적합도를 계산한다.
  1. 알레르기·과거 이상반응
  2. 복용약·치료·임신·수유 등 전문가 승인 규칙
  3. 원료 금지·제한·제품 사용기한
  4. 중복 기능·병용 규칙·사용 순서
  5. 피부 상태·날씨·과거 사용 결과
- 농도나 제형 정보를 알 수 없는 타 브랜드 제품은 정밀한 호환성을 단정하지 않고 보수적으로 안내한다.
- 사용자가 이미 가진 제품을 우선 사용하고, 필요한 제품만 패키지에 넣는다.

### 3.5 주간 팩·배송

**사용자 가치:** 매일 다른 화장품을 복잡하게 고르지 않고, 필요한 구성만 받는다.

- `코어`: 세정·기본 보습·자외선 차단처럼 자주 바꾸지 않는 제품 3~4종
- `적응 모듈`: 보습 강화·유분 조절·진정·UV 대응 중 필요한 제품 3~5종
- `비상 모듈`: 건조·자극이 예상보다 심해졌을 때 사용할 순한 보습·진정 제품
- D1~D3는 구체적으로 계획하고, D4~D7은 `Dry·UV·Calm` 선택형 모듈을 넣어 앱이 당일 사용 모듈을 지정한다.
- 사용자가 이미 가진 제품은 패키지에서 빼고 다른 필요 모듈로 교체할 수 있다.
- MVP는 제조사가 포장한 밀봉 미니 제품 또는 ODM 일회분만 사용하고, 임의 소분·혼합과 냉장 제품은 제외한다.

### 3.6 오늘의 루틴 안내

**사용자 가치:** 앱을 열자마자 오늘 무엇을 어떻게 바를지 안다.

- 아침·저녁 제품, 사용 순서, 부위, 양, 대기시간을 하나의 카드로 표시한다.
- 루틴이 바뀐 이유를 `피부·날씨·이상반응`을 기준으로 한 문장으로 알려준다.
- 처음 쓰는 제품에는 제조사 사용법에 따른 국소 확인과 이상반응 대처법을 표시한다.
- `AR Skin Navigation`은 후속 기능으로, 얼굴 위에 사용 부위·양·순서를 표시한다.

### 3.7 피드백·SOS·피부 기록

**사용자 가치:** 사용 결과를 다음 추천에 반영하고, 문제가 생기면 즉시 안전한 루틴으로 전환한다.

- 매일 10초 피드백: 사용 여부, 건조·유분, 따가움·가려움·붉어짐
- 주 1회 같은 조건에서 재촬영하고 변화 추세를 확인한다.
- `SOS`를 누르면 최근 72시간의 사용 제품과 조합을 확인한다.
- 의심 제품을 일시 중단하고 비상 모듈 중심의 보습·진정 루틴으로 재편성한다.
- 증상이 심하거나 지속되면 질환명을 단정하지 않고 전문 의료기관을 안내한다.
- 재촬영 결과, 사용 제품, 이상반응, 날씨에 따른 변화를 `피부 기록`에 통합한다.

## 4. 기능 통합 원칙

아래 요소는 독립 기능이나 별도 메뉴로 만들지 않는다.

| 기능 아이디어 | 통합 방식 |
|---|---|
| 화장대 스캔·화장품 절약 | `루틴 디자이너`가 보유 제품을 먼저 쓰고 필요한 제품만 추가하도록 통합 |
| 성분 충돌·루틴 시뮬레이터 | `Skin Firewall`이 사용 전 검사하고 제품 변경 시 루틴을 재계산 |
| 여행·야외 활동·실내 습도·중요 일정 | 별도 모드가 아닌 `이번 주 조건`으로 입력받아 필요할 때만 루틴을 재계산 |
| Skin Passport | 재촬영·사용·이상반응·날씨 기록을 모은 `피부 기록`으로 통합 |
| 사용량 인식 | `오늘의 루틴`의 AR 안내에 후속 통합 |
| 패키지 제품 교체 | 보유 제품을 빼고 필요 모듈만 고르는 `주간 팩`에 통합 |

## 5. 최소 화면 구조

주요 탭은 4개만 사용하고 `SOS`는 오늘 화면에 항상 노출한다.

| 탭 | 핵심 내용 |
|---|---|
| **오늘** | 아침·저녁 루틴, 바뀐 순서·부위·양, 루틴 변경 이유, 10초 피드백, SOS |
| **스캔** | 피부 재촬영, 화장품 등록, Skin Firewall 결과 |
| **주간 팩** | 팩 구성, 보유 제품 제외·교체, 주문·배송 |
| **내 피부** | 피부 지표와 신뢰도, 주간 변화, 사용·이상반응 기록, 안전 프로필 |

## 6. MVP 범위

### 필수 구현

1. 안전 프로필과 개인정보 동의
2. 3각도 촬영과 자동 품질 검사
3. 5~6개 시각 피부 지표, 추정 위험도와 신뢰도 표시
4. 7일 날씨·UV를 반영한 루틴 제안
5. 보유 화장품 등록, 안전 검사와 루틴 재편성
6. 코어·적응·비상 모듈로 구성된 7일 팩
7. 오늘의 루틴 카드와 10초 피드백
8. SOS 제품 중단·회복 루틴 전환·전문기관 안내
9. 주 1회 재촬영과 변화 기록

### 후속 구현

- AR Skin Navigation과 실시간 사용량 인식
- 여행·야외 활동·실내 습도·중요 일정 조건
- 미세먼지·스마트기기·웨어러블 정보 연결
- 피부과·전문가 연계용 기록 공유
- 제조사·ODM이 검증한 제품 선택지 확대

### 제외

- 피부질환의 확정 진단·치료·처방
- 사업자가 다른 브랜드 제품을 임의로 소분·혼합하는 기능
- 냉장·냉동 유통과 수백 개 SKU
- 정보가 부족한 제품의 정확한 성분 상호작용 단정
- 수분·피지·민감도를 스마트폰으로 직접 계측했다는 표현
- 광고비에 따라 추천 순위가 바뀌는 구조

## 7. 운영자 기능

사용자 앱을 복잡하게 만들지 않도록 아래 기능은 운영 시스템으로 분리한다.

| 영역 | 필수 기능 |
|---|---|
| **제품·성분** | SKU, 제형·전성분 버전, 사용법, 주의사항, 알레르기 정보 관리 |
| **규정** | 규정 버전·시행일, 제품 표시사항, 원료 금지·제한 규칙 관리 |
| **안전** | 알레르기·병용·이상반응 규칙, 전문가 승인 이력, 추천 보류·전문기관 전환 관리 |
| **재고·품질** | lot, 사용기한, 바코드, FEFO 출고, 대체 SKU, 폐기·품절 관리 |
| **주문·배송** | 주간 팩 조립, 주문별 lot 추적, 배송 상태, 오배송·회수 처리 |
| **AI 품질** | 촬영 QC, 신뢰도·학습 분포 이탈·모델 불일치, 연령·피부톤·기기군별 성능 격차 모니터링 |
| **개인정보** | 동의 버전, 보유기간, 원본 사진 삭제, AI 학습 제외, 접근 기록 관리 |
| **모니터링** | 이상반응, SOS, 추천 보류율, 루틴 이행률, 피드백 완료율, 재구매·유지율 확인 |

재고는 추천 안전성과 예상 효과가 동등한 후보 사이에서만 순위 결정에 사용한다. 재고 소진을 위해 더 부적합한 제품을 추천하지 않는다.

## 8. 운영·안전 원칙

- 모델 점수보다 안전 규칙을 먼저 적용한다.
- 피부질환을 진단하지 않고, 위험 신호에서는 추천을 보류한다.
- 서버는 얼굴 인식용 신원 특징값을 만들지 않는다.
- 원본 사진은 최소 기간만 보관하고 사용자가 삭제할 수 있게 한다.
- 제품은 `SKU → 제형 버전 → 전성분 버전 → lot → 사용기한 → 주문`으로 추적한다.
- 추천 순위와 광고·협찬 영역을 분리한다.

## 9. 성공 기준

사용자가 매일 여러 화면을 공부하지 않고도 다음 세 가지를 즉시 이해하면 성공이다.

1. **오늘 무엇을 바를지**
2. **왜 어제와 다른지**
3. **문제가 생기면 무엇을 멈춰야 하는지**

핵심 차별점은 피부 점수가 아니라 **피부·날씨·보유 화장품·이상반응을 함께 고려해 실제 사용 루틴을 계속 조정하는 것**이다.
